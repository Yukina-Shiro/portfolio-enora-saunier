Le Contexte

Anime Squad Battle est une application web interactive de type "Gacha" (collection de cartes) combinée à un jeu de gestion d'équipe stratégique, fortement inspirée du mode Ultimate Team de la franchise FIFA, mais transposée dans l'univers des anime (Naruto, Dragon Ball, One Piece, Jujutsu Kaisen, etc.). Le joueur commence avec un montant de monnaie de départ, invoque des personnages en ouvrant des packs, compose la meilleure formation possible sur le terrain en respectant les rôles, et affronte d'autres joueurs pour gagner des pièces et améliorer son équipe. Ce projet a été réalisé dans le cadre d'un projet universitaire Fullstack, mettant en avant une séparation stricte entre une API REST robuste et une architecture Frontend (SPA) moderne en Vanilla JS.

Mes Missions & Réalisations

J'étais en charge de la conception de l'architecture globale, du développement de l'API Backend et de l'intégration de l'interface Frontend :

  • Développement de l'API REST avec Java Spring Boot 3 et persistance des données via Hibernate/JPA sous PostgreSQL.
  • Intégration d'une interface utilisateur dynamique (SPA) en Vanilla JavaScript et stylisée avec Tailwind CSS (Thème Néon/Cyberpunk).
  • Création d'un système interactif en Drag & Drop pour la gestion de la formation sur le terrain, avec sauvegarde asynchrone instantanée.
  • Sécurisation de l'économie du jeu (achats de packs, système de marché) via la gestion stricte des transactions (@Transactional) pour éviter les failles de duplication ou de soldes négatifs.

Ce que j'ai appris

Ce projet m'a permis de maîtriser la création d'une architecture backend robuste (contrôleurs, services, DTO) et de comprendre les enjeux de la synchronisation d'état côté client sans utiliser de framework lourd comme React. J'ai également renforcé mes compétences dans la gestion asynchrone (Promises, appels Fetch avec intercepteurs d'erreurs) et la conception de bases de données relationnelles complexes.
