Le Contexte

L'objectif de ce projet était de créer un site web dynamique complet permettant de gérer le catalogue d'une médiathèque. Le site devait offrir une interface pour les utilisateurs (consultation, recherche) et une interface d'administration pour gérer les stocks (livres, DVD, CD).

Mes Missions & Réalisations

J'ai travaillé sur l'ensemble de la chaîne de développement, de la base de données à l'interface utilisateur :

  • Architecture CRUD : Développement des fonctionnalités Create, Read, Update, Delete pour la gestion des médias.
  • Base de Données : Conception du modèle relationnel (MCD) et requêtes complexes en SQL pour filtrer les œuvres par genre, auteur ou disponibilité.
  • Communication PHP/MySQL : Création de scripts PHP pour connecter le site à la base de données et sécuriser les entrées utilisateurs.
  • Intégration Web : Mise en page du site en HTML5 et CSS3 respectant un cahier des charges précis.

Ce que j'ai appris

Ce projet a été fondamental pour ma compréhension du développement web dynamique. J'ai appris à structurer un site complexe, à manipuler des données en temps réel et à comprendre l'importance d'une base de données bien modélisée.
